# Mihomo 代理分组层级设计

## 层级关系（自上而下）

```
GLOBAL (select, 默认: DIRECT)
├── 漏网之鱼               ← MATCH 兜底
├── 节点选择               ← 手动选节点
├── 手动切换               ← 逐节点选
├── 自动选择               ← url-test 测速
├── 国外媒体               ← 国外流媒体/社交
├── 国内媒体               ← 国内服务
├── 广告拦截               ← REJECT
├── 应用净化               ← REJECT
├── [规则分类组]            ← AI服务/加密货币/游戏等
├── DIRECT                 ← 内置
└── [地理组]               ← 🇭🇰 香港/🇯🇵 日本/...

漏网之鱼 (select, 默认: 节点选择)
├── 节点选择, 手动切换, 自动选择, DIRECT

节点选择 (select, 默认: 自动选择)
├── 自动选择, 🇭🇰 香港, 🇯🇵 日本, ..., DIRECT

手动切换 (select, 默认: 第一个地理组)
├── 🇭🇰 香港, 🇯🇵 日本, ..., DIRECT

自动选择 (url-test, 默认: 自动测速)
├── [所有地理节点]

广告拦截 (select, 默认: REJECT)
├── REJECT, 节点选择, 自动选择, DIRECT

应用净化 (select, 默认: REJECT)
├── REJECT, 节点选择, 自动选择, DIRECT

国外媒体 (select, 默认: 自动选择)
├── 自动选择, 节点选择, 手动切换, 🇭🇰 香港, ..., DIRECT

国内媒体 (select, 默认: DIRECT)
├── DIRECT, 节点选择, 手动切换, 自动选择

[规则分类组] (select, 默认: 节点选择)
├── 节点选择, 手动切换, 自动选择, 🇭🇰 香港, ..., DIRECT

[地理组] (select, 默认: 自动选择)
├── 自动选择, 节点1, 节点2, ...
```

## 规则路由逻辑

每条规则的出口目标由 `ruleActionTarget()` 计算：

| 规则目标 | 所属规则大类 | → 路由目标 |
|----------|-------------|-----------|
| REJECT | 安全与隐私(广告拦截) | `广告拦截` |
| REJECT | 安全与隐私(应用净化) | `应用净化` |
| PROXY | 流媒体 | `国外媒体` |
| DIRECT | 流媒体(哔哩哔哩/优酷等) | `国内媒体` |
| DIRECT | 中国内地常用 | `国内媒体` |
| PROXY | 其他大类(AI/加密/游戏/社交等) | `[大类名]` |
| — | 硬编码 GEOIP,private/GEOSITE,cn | `DIRECT` |
| — | 硬编码 GEOSITE,category-ads-all | `广告拦截` |
| — | GEOIP,CN | `DIRECT` |
| — | MATCH | `漏网之鱼` |

## 生成规则

1. **始终生成**（无论规则选择）：GLOBAL, 漏网之鱼, 节点选择, 手动切换, 自动选择, 广告拦截, 应用净化, 国外媒体, 国内媒体, 地理组
2. **条件生成**（仅当该大类有规则被勾选时）：AI 服务, 加密货币, 游戏平台, 社交, 云服务, 开发工具, 其他常用
3. **不生成**（规则被合并到上位分组）：安全与隐私(→广告拦截/应用净化), 流媒体(→国外媒体/国内媒体), 中国内地常用(→国内媒体)
