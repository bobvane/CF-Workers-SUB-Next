## 🎯 核心策略组（始终生成）

```
GLOBAL (select, 默认: 自动选择)            ← 最终兜底
├── 节点选择               (select, 默认: 自动选择)
├── 手动切换               (select, 默认: 第一个节点)
├── 自动选择               (url-test, 默认: 自动测速)
├── 国外媒体               (select, 默认: 自动选择)
├── Google服务             (select, 默认: 手动切换)  v2.15.0 新增
├── 广告拦截               (select, 默认: REJECT)
├── 微软服务               (select, 默认: 自动选择)  v2.19.5 修改
├── 苹果服务               (select, 默认: DIRECT)
├── 游戏平台               (select, 默认: DIRECT)
├── AI 平台                (select, 默认: 手动切换)
├── 社交                   (select, 默认: 自动选择)
├── 加密货币               (select, 默认: 🇹🇼 台湾)
├── 用户规则               (select, 默认: 手动切换)
├── 漏网之鱼               (select, 默认: 手动切换)  v2.19.5 修改
└── [地理组]               (🇭🇰 香港/🇯🇵 日本/...)
```

### 策略组详细说明

| 策略组 | 类型 | 默认出口 | 说明 |
|--------|------|---------|------|
| **GLOBAL** | select | 自动选择 | 顶层组，决定面板节点组显示顺序（v2.19.5 改为自动选择） |
| **节点选择** | select | 自动选择 | 用户手动选地区/节点方案 |
| **手动切换** | select | 第一个节点 | 逐节点选（优先美国组第一个节点） |
| **自动选择** | url-test | 自动测速 | 按地理组测速，挑最优地区（v2.19.4 改为按地理组而非扁平节点） |
| **国外媒体** | select | 自动选择 | 流媒体 PROXY |
| **Google服务** | select | 手动切换 | Google 服务分流（v2.15.0 新增） |
| **广告拦截** | select | REJECT | 只保留 REJECT 和 DIRECT 两个选项 |
| **漏网之鱼** | select | 手动切换 | MATCH 兜底（v2.19.5 从自动选择改为手动切换） |

| 业务组 | 默认出口 | 说明 |

## 🌍 地理策略组

按节点 IP 国家码自动生成：

- **基础地理组**（有 1 个节点即生成，select 类型）：🇭🇰 香港、🇬🇧 英国、🇩🇪 德国 等
- **自动测速地理组**（有 ≥2 个节点升级为 url-test）：🇺🇸 美国、🇲🇾 马来西亚、🇯🇵 日本、🇸🇬 新加坡、🇹🇼 台湾、🇰🇷 韩国
- **未识别地理组**：「其他」组（无法识别国家码的节点）

### url-test 参数

```yaml
type: url-test
url: http://www.gstatic.com/generate_204
interval: 300
tolerance: 50
```

## 🔀 规则路由逻辑

每条规则的出口目标由 `ruleActionTarget()` 计算：

| 规则目标 | 所属规则分组 | → 路由目标 |
|----------|-------------|-----------|
| REJECT | ads（广告拦截） | `广告拦截` |
| DIRECT | 内网防代理 / 国内直连 | `DIRECT` |
| PROXY | media（国外媒体） | `国外媒体` |
| PROXY | google-fcm | `谷歌FCM` |
| PROXY | microsoft | `微软服务` |
| PROXY | apple | `苹果服务` |
| PROXY | game | `游戏平台` |
| PROXY | ai | `AI 平台` |
| PROXY | social | `社交` |
| PROXY | crypto | `加密货币` |
| PROXY | user（用户规则） | `用户规则` |
| — | MATCH | `漏网之鱼` |

## 📋 规则输出顺序（buildRules）

按 RULE_GROUPS 数组顺序输出：

```
① 内网防代理 (GEOIP,lan + GEOSITE,private)        → DIRECT
② 用户自定义规则                                → 用户规则
③ 广告拦截 (CATEGORY-ADS-ALL)                   → REJECT
④ 国内直连 (GEOSITE,cn)                         → DIRECT
⑤ 国外媒体 / Google服务 / 业务分类组 / 微软服务 / 苹果服务 / 游戏平台 / AI / 社交 / 加密货币
⑥ GEOIP,CN                                     → DIRECT
⑦ MATCH                                        → 漏网之鱼
```

### 硬编码规则（始终输出，不依赖勾选）

```yaml
- GEOIP,lan,DIRECT,no-resolve
- GEOSITE,private,DIRECT
- GEOSITE,cn,DIRECT
- GEOIP,CN,DIRECT
- MATCH,漏网之鱼
```
